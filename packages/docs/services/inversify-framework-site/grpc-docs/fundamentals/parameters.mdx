# Parameters

With no parameter decorators, the adapter calls the method the way `@grpc/grpc-js` calls a raw handler: `(call, callback)` for unary and client-streaming RPCs, and `(call)` for server-streaming and bidirectional RPCs.

Add a parameter decorator when you want the container to build the argument list. `@Call()` injects the call. `@Callback()` injects the `sendUnaryData` callback. A [custom parameter decorator](../pipe) injects a value you compute from the call. After the first parameter decorator, every argument you need has its own decorator. An undecorated parameter is `undefined`.

`@Callback()` belongs on unary and client-streaming methods. Server-streaming and bidirectional RPCs have no callback, and `build()` throws if one of those methods uses `@Callback()`.

When a method uses `@Callback()`, that callback sends the response. The adapter leaves the return value alone.
