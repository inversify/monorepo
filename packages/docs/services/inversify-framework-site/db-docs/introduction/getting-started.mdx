# Getting started

`@inversifyjs/prisma` binds a Prisma 7 client into the InversifyJS container using a driver adapter, so your services can inject `PrismaClient` and talk to the database.

:::note[PostgreSQL is just an example]

These guides use PostgreSQL with `@prisma/adapter-pg`, but `@inversifyjs/prisma` works with any Prisma 7 driver adapter. Swap the adapter, datasource provider, and connection options for your database of choice.

:::

## Install dependencies

Install `@inversifyjs/prisma`, `inversify`, Prisma, and the PostgreSQL driver adapter:

<Tabs>
  <TabItem value="npm" label="npm">

```bash
  npm install inversify @inversifyjs/prisma @prisma/client @prisma/adapter-pg pg
  npm install -D prisma
```

  </TabItem>
  <TabItem value="yarn" label="yarn">

```bash
  yarn add inversify @inversifyjs/prisma @prisma/client @prisma/adapter-pg pg
  yarn add -D prisma
```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

```bash
  pnpm add inversify @inversifyjs/prisma @prisma/client @prisma/adapter-pg pg
  pnpm add -D prisma
```

  </TabItem>
</Tabs>

Generate your Prisma client after configuring a PostgreSQL `schema.prisma` (and preferably a custom `output` outside `node_modules`).
