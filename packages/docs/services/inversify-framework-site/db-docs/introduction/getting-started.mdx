# Getting started

`@inversifyjs/prisma` binds a Prisma 7 client into the InversifyJS container using a driver adapter, so your services can inject `PrismaClient` and talk to the database.

## Install dependencies

Install `@inversifyjs/prisma`, `inversify`, Prisma, and a driver adapter for your database:

<Tabs>
  <TabItem value="npm" label="npm">

```bash
  npm install inversify @inversifyjs/prisma @prisma/client
  npm install -D prisma
  # PostgreSQL
  npm install @prisma/adapter-pg pg
  # or SQLite
  npm install @prisma/adapter-better-sqlite3 better-sqlite3
```

  </TabItem>
  <TabItem value="yarn" label="yarn">

```bash
  yarn add inversify @inversifyjs/prisma @prisma/client
  yarn add -D prisma
  # PostgreSQL
  yarn add @prisma/adapter-pg pg
  # or SQLite
  yarn add @prisma/adapter-better-sqlite3 better-sqlite3
```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

```bash
  pnpm install inversify @inversifyjs/prisma @prisma/client
  pnpm install -D prisma
  # PostgreSQL
  pnpm install @prisma/adapter-pg pg
  # or SQLite
  pnpm install @prisma/adapter-better-sqlite3 better-sqlite3
```

  </TabItem>
</Tabs>

Generate your Prisma client after configuring `schema.prisma` (and preferably a custom `output` outside `node_modules`).
